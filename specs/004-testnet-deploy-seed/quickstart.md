# Quickstart: Testnet Deployment + Demo Seed (Feature 004)

**Feature**: 004-testnet-deploy-seed · **Gates**: spec SC-001..SC-006 · Interface
contract: [contracts/deploy-seed-api.md](contracts/deploy-seed-api.md) (script CLI,
artifact shapes, abort messages). Commands run from the **repo root**; forge flags
AFTER the subcommand (1.5.x syntax). §0 setup is user-side (funded wallet); §1–§2 are
local and runnable from a fresh clone; §3–§7 are the live-chain Done-when.

## §0 Prerequisites

- Foundry ≥ 1.x (already required by Features 002/003).
- **MON**: a deployer wallet funded via `https://faucet.monad.xyz` (≥ 0.5 MON; the
  deploy preflight enforces it).
- **Env**: `cp contracts/script/env.example` → fill a private `.env` (gitignored).
  Required: `DEPLOYER_KEY`, `RELAYER_KEY`, `ORCHESTRATOR_KEY`, `PAUSER_ADDR`,
  `BUDI_KEY`, `PAKHAJI_KEY`, `SITI_KEY`, `WATI_KEY`, `MILL_KEY`, `MILL_CHANNEL_NAME`.
  Optional: `AUSD_ADDRESS` (real-asset path, behind the preflight), `EXPLORER_API_KEY`.
- **Real-AUSD attempt (optional)**: Agora's faucet `0xd236…ee6C` (`requestFunds`,
  10,000/call) is documented on Sepolia only — on Monad it is an experiment; the
  `SEED_AUSD_MIN` (14,000e6) preflight decides, and the default MockAUSD path needs
  nothing.

## §3 Deploy + verify (SC-003)

```sh
source .env && forge script contracts/script/DeployKiteCore.s.sol --root contracts \
  --rpc-url "$RPC_URL" --broadcast --slow -g 115 \
  --verify --verifier etherscan --verifier-url https://api-testnet.monadscan.com/api
```

**Expected**: exit 0; manifest prints asset/impl/proxy/channel addresses + Monadscan
URLs; every URL opens **verified source**; on-chain reads show RELAYER_ROLE and
ORCHESTRATOR_ROLE on exactly the env wallets and `minEventGap()==60`. Verification
trouble → research D11's retry; the gate stays open until green.

## §4 Seed — the §6.3 prepared state on the public chain (SC-001)

```sh
bash contracts/script/seed-demo.sh        # prints wall-clock plan (~5 min), then stage 1 → (sleep 70s → stage 2..5)
```

One qualifying event per stage; the sleep lands before each qualifying event after
E1 — four sleeps total (per-event gap rule). **Expected**: stage 5's assert block
all-PASS, then the two Done-when reads:

```sh
cast call "$KITE" "scoreOf(address)(uint8)" "$BUDI" --rpc-url "$RPC_URL"          # → 58
cast call "$KITE" "isaOf(uint256)(…)" 3 --rpc-url "$RPC_URL"                       # → ISA-3: P 600e6, remaining 480e6, status Active(2)
```

(Exact `isaOf` output shape = the 003 API tuple; the assert block already checked
every literal — these two commands are the unaided user verification.)

`CompletedCapped`, remaining 0, and a further income attempt reverts (terminal).
